# SnackDash V2｜横屏美术资产制作手册

**制作版次 r02 · 2026-11-26 · 适用对象：原画、动效、UI、素材整理与验收人员**

本轮从东京做起。先用手机横屏灰模确定玩家能读清哪些数字，再画同一位补给员在桌后换水、登桌、投出水瓶的全过程。东京男女两款在三种模式下都成立后，才把做法扩到其余城市。本文提供工序、出图指令、数量口径和验收方法；文中的交付清单表示待制作内容。

## 1. 制作基准和参考图

| 项目 | 本版执行标准 |
| --- | --- |
| 画面与机位 | 手机横屏。以 16∶9、1280×720 做构图与坐标母版。三条跑道向同一消失区汇聚，选手从远处迎面跑来。左侧是玩家操作的补给站，近景仍能同时辨认三条道。 |
| 屏幕边界 | 顶部留比赛 HUD、模式与节庆标题。左下恰好两个备用补给槽，上下排列。桌体、地平线、跑道及控件在同一城市三态中对齐。宽屏优先展开两侧街景；异形屏按设备安全区内收控件。 |
| 读图顺序 | 先看手中补给数值和目标胸牌，再看飞行物与命中结果，最后才看服装、观众、花瓣与烟花。近景人物要有可见的手、脸和胸牌；道路宽度随同人物尺度一起调。 |
| 一只手、一件实物 | 准备或持有时，手中清楚握住一件马拉松补给。出手后同一件物体沿弧线飞行，掌心松开。手边气泡的全部内容是**一个完整数值**，如 `6` 或 `13`。气泡内无瓶子、香蕉、凝胶、文字、单位或其他图案。 |
| 三种模式 | Normal 城市日常，Fever 当地节庆升温，Inferno 庆典高潮。前两态补给员站桌后；Inferno 实际登上**原桌面**，从更高的手位投掷，结束后下桌。女性长袍或长裙从腰部自然垂落，全程遮腿。 |
| 角色与语言 | 可选男、女补给员，选择独立于界面语言。跑者穿现代跑装，国籍档案提供母语，外观独立设计。跑者反应气泡只排该选手的母语短句。节庆标题另排当地原名和玩家语言说明。 |
| 参考的边界 | 选定的东京 Inferno 图用于取画风、实体投掷、数字气泡与节庆氛围。图里的字号、烟花密度、城市透视、装饰文字都要经过实机尺寸试排。旧资料中的 390×700 竖屏描述在本手册中统一换为横屏。 |

**先打开这两份参考。** 东京确认图里，左侧的补给员手里握着水瓶，头侧的白气泡只有深色的 `6`。左下两格各自显示物品图标和数值，飞出去的水瓶还有能辨认的瓶颈。这三处分别传达数量、可换物品和动作结果，出图时要逐处复查。[东京确认图原图](https://github.com/erlinmm/SnackDash/blob/974ca5a6043f488952800da61c604b867e7987f0/assets/previews/character-r01/originals/tokyo_inferno_supply_number_only.png) · [r01 五张参考图与说明](https://github.com/erlinmm/SnackDash/blob/974ca5a6043f488952800da61c604b867e7987f0/assets/previews/character-r01/README.md)

随附过的 r01 ZIP 含四张角色与群像板，素材分支另归档一张东京确认图。跑者板只探索了 KE、TZ、JP、KR、CN 五国。图中文字、国旗及人物面孔均以源档复核。已有的 22 份跑者、60 份服装、30 组群像是设计条目，成品数量按后文的实际文件和验收记录另计。

**此前参考怎样落实在画面里。** 把 Block Blast 的操作对象优先落实为胸牌和补给数字的明暗对比；把 Color Block Jam 的圆角体积感用在瓶盖、凝胶封边和备用槽边框；把 Royal Kingdom 的轮廓辨识度用在六套东京补给员服装。借鉴 Balatro 的是得分框随连击升温、在高潮处短促爆燃的节奏。SnackDash 的火花集中在分数边框和出手点，跑道中央留给算术判断。这些是本项目选择的画法。

## 2. 怎样使用本手册里的生成指令

1. **参考按职责附上。** 第一次出图附东京确认图。之后每次只加与该任务有关的已选母版，例如人物正面图、场景灰模或上一动作关键帧。服装拓展再附附录 B 对应的一行。记录参考文件名和版本。
2. **每次只换一个变量。** 同一人物先定脸型、身高、持物手与鞋底基线，再分别生成服装和姿态。修改袖口时沿用已选图，只编辑袖口区域。每个候选保留自己的版本号。
3. **区分出图和排版工序。** 下文“出图”可直接给图像工具。带精确数字、坐标、图层、透明通道、帧矩形或设备实测的部分交给美术或排版工具完成。“制作指令”可直接交给操作者。概念图只作为可编辑母稿的底稿。
4. **占位符先填再用。** `{城市}` 取附录 B 的城市，`{模式}` 取 normal / fever / inferno，`{人物描述}` 取附录 A，`{服装}` 或 `{观众道具}` 取附录 B 对应格，`{实物}` 取水瓶、凝胶、香蕉等。只在评审合成里用真数字与真实文字。

**所有插画指令共用的画风段。** 复制下面一段，再接对应步骤的指令。若要生成灰模、排版、导出文件或生成音效，则直接用该步骤的制作指令。

```text
沿用所附 SnackDash 东京图的干净节庆卡通画风。人物轮廓利落，脸部表情简明，手掌与物体的接触清楚。采用有节制的赛璐璐阴影，主体亮面集中，背景细节柔和。让深浅肤色在白天、粉色节庆光和夜间金光里都保留本色。按手机横屏实际观看大小组织细节。人物和道具画成独立组件时，轮廓完整、四周留边、背景透明。场景按要求画到边。印字、游戏数字、标牌名称留给独立排版层。
```

## 3. 从参考图到可交付资产的 12 步

### 01｜确定横屏机位和安全区

**输入与需求。** 东京确认图、16∶9 空白画板。用同一组近中远跑者、一个桌体、两个下方控件，比较两个机位。A 给左站较多宽度，B 给最靠左的跑道较多宽度。评审中用桌宽和消失点解释两者差异。确定草图后才记录坐标。

**出图指令**

```text
画一张 16:9 手机横屏马拉松益智游戏构图灰模，只用灰阶和一种强调色。机位坐在赛道终点一侧，正面看三条来向跑道和朝镜头跑来的选手。把左侧补给桌、桌后补给员、左下上下两个空白备用槽、顶部空白 HUD 和右侧道路都画在同一幅场景里。摆入近中远三层成年跑者及两侧护栏。桌沿高度要能支持一个成年人登桌；上方给站在桌上的头、掌中水瓶和数字气泡留空间。交一张完整横屏稿。第二稿只改变左站宽度与消失点，使用完全相同的人物和控件。
```

**第一张灰模的试排数据。** 用同一组独立占位层给 A、B 两稿加上手边 `6`、备用 `4` 和 `8`、前排胸牌 `12`、`18`、`24`。再把一名中景跑者换成四位数 `1000`。数字由排版工具放入，以便两稿做等条件比较。

**交件与验收。** 两张灰模、选定稿的安全区图和坐标表。安全区标出顶部 HUD、两槽点击范围、三道胸牌可能经过的区域、持物手与气泡、可裁掉的街景。用 1280×720 排一次，用 640×360 缩览，再用一宽一窄横屏框试裁，例如 19.5∶9 与 4∶3。较窄框先收侧景、调整间距，必要时给核心画面留边。三道、两槽、胸牌与手的完整性必须一起成立。实际像素与触控大小在设备检查时记录。

### 02｜锁定画风、光色和角色比例

**输入与需求。** 东京确认图、步骤 01 选定灰模。取同一个成年跑者、一个补给员、一只透明水瓶和一面护栏做风格标尺。先比较轮廓和阴影，再用同一组物体验证三种光照。人物比例试稿可从约 3.5–4.5 头身起步，以小屏脸、手和胸牌可读为准。

**出图指令**

```text
制作一张东京角色与材质色稿。画同一位成年跑者、同一位补给员、同一只带蓝盖的水瓶与一小段护栏。做三个横向并排的小场景，保持机位、脸、姿态、物体比例相同。Normal 是清爽日光；Fever 加入樱粉布料和暖灯；Inferno 用靛蓝夜色衬托少量金紫烟花。近景人物边缘清晰，胸前留白色号码布，所有文字留空。下方另给瓶盖、头发、布料、皮肤各一个放大细节，展示各自受光方式。
```

**交件与验收。** 选一套明暗关系、轮廓粗细和角色比例，记录主辅色样及其用途。把三态都缩到手机大小，用灰阶再看一遍。最先认出的是号码布、脸和瓶子；同一个人从日光切到夜光仍可辨认。用“把远景灯笼压暗一级”等可执行改稿意见记录选择。

### 03｜建立东京街景、固定桌体与图层

**输入与需求。** 已选机位、色稿、东京街景方向。远处用东京轮廓与河岸，近处用铺地、灯笼、护栏、行道树或无字贩卖机交代城市。路面要有明度安静的区域供跑者经过。桌面、桌前挡板分开，桌腿与人物脚的前后关系可单独调整。

**出图指令**

```text
按所附横屏灰模画东京马拉松赛道 Normal 空场母版。保留原消失点与三条跑道，各条标线进入同一透视。左右街景能在较宽屏幕上继续向外延伸。远处做河岸和可辨认的东京天际线，中景做护栏、浅灰铺地、灯笼与树，路中心简洁。左站的位置留空，天空留出节庆光效的位置。此次只输出空场，不画人物、文字和 UI。另一次出图只画与该透视吻合的一张实体补给桌，明确水平桌面、前挡板、桌脚和上桌接触面，透明底；保留可独立换图的挡板正面。
```

**交件与验收。** 输出天空与天际线、地面与标线、两侧街景、护栏、桌后部和桌前板。三态共享同一份道路和桌体，Fever 加樱花和布幔，Inferno 加夜色与花火面板。把人物放在桌后和桌上各看一次，后者能看出鞋底或长袍下缘与桌面接触。合上或关闭任一装饰层，跑道都完整。换城市时先替换铺地、街具和地标，保留已过审机位。

### 04｜制作实体补给、双备用槽与手边数字气泡

**输入与需求。** 东京首包先做瓶装水、补给凝胶、香蕉。每种分别画手持、飞行、备用槽图标三种用途；可从同一母稿转角度。水瓶靠瓶颈和瓶盖识别，凝胶是带撕口的扁软袋，香蕉用弯曲剪影。物品外观独立于数值，水瓶也可以对应不同数字。

**出图指令**

```text
画一件原创无品牌的马拉松补给：{实物}。交一张独立透明底素材。第一版用斜三分之四视角，轮廓适合握在补给员手中，握点留在物品重心附近。第二版沿同一个物体转成清晰的飞行角度。第三版简化为小尺寸备用槽图标，保留关键轮廓和主色。包装只用色块与材质，不写数字和品牌。为水瓶、可撕口的扁补给凝胶袋和带柄香蕉分别执行。再独立画一个白底深边空数字气泡和一个空备用槽底板，二者各自成图。
```

**制作与验收。** 每一件输出透明 PNG，另交一张组装校样。给手的前后指分层，让拇指压住实物；投出帧掌心清空，飞行物沿同一手位出发。排版工具将 `6`、`12`、`13` 轮流置入手边气泡。左下恰好两槽，槽内保留**图标＋数值**；手边气泡只出现**数值**；空中只出现**实物**及适度拖尾。两槽的尺寸与点击范围独立于桌子。用黑白、深蓝两种底色检查透明边缘。

**与旧资源的对应。** 已核对的 `main2` 游戏补给键为 `water`、`banana`、`apple`、`orange`、`bar`、`juice`。覆盖现有外形时还需补苹果、橙子、能量棒、果汁。凝胶是 V2 明确要画的外形，先建美术项 `gel`，映射留给后续接入决定。[原有补给类型与数值范围](https://github.com/erlinmm/SnackDash/blob/da52244ddab30a1336d28dc33d6f5234c60e56af/src/js/math.js)

### 05｜制作迎面跑者母版与 22 份选角

**输入与需求。** 步骤 02 色稿、附录 A 的一条人物描述。东京首样建议选 KE 女、JP 男，用同一张胸牌底测试长短发、深浅肤色与不同体态；这只是首批抽样。其余按附录逐条完成。将体型、面部、发型、肤色、运动装和配饰作为可复用的独立选择。

**出图指令**

```text
按以下选角描述画一名原创成年长跑选手：{人物描述}。交一张透明底、全身、正面朝镜头的单人跑姿母稿。双眼面向前方，肩与骨盆显示自然反向扭转，一脚承重，另一脚离地，脸、双手与两只鞋都完整。穿现代无品牌背心和跑鞋，胸前单独留深边浅色号码布，两臂摆动时避开中央读数区。基于选定母稿，另给同一人的接补给姿势与微笑致谢表情。保持脸、衣纹大块、身高和号码布位置一致。
```

**交件与验收。** 一名选手一张整身母稿、一组可拆部件、标准正面跑姿和手接补给姿势；动作共用模板见步骤 07。跑者正面、头顶、鞋底、胸牌有固定参考点。将 `8`、`48`、`168`、`1000` 叠在近中远胸牌上，摆动的手和马尾都避开数字。选角总表检查至少 8 档肤色、6 类发质／发型、3 种脸部轮廓、3 种体态，以及成年年龄差异。让国籍、母语与外观分别登记；跨国复用发型和肤色是预期行为。

### 06｜做出东京同一对补给员的六套造型

**输入与需求。** 固定一位女性和一位男性的脸型、发际线、身高、惯用手及鞋底点；每人独立做 Normal、Fever、Inferno。完整身体、服装、手臂、袖口、发饰、手中道具分别输出。换装要能从轮廓和面料看出升级。

**出图指令**

```text
先生成东京女性补给员的 Normal 单人全身母稿，蓝米色 happi 风短外套、腰带、简洁发花，三分之四朝向画面右侧的跑者，一手可自然握瓶。随后分别编辑同一人：Fever 用樱粉浴衣、清楚的腰带与适合抬手的短袖口；Inferno 用靛紫长和服、金色花火纹与精细腰带，长袍自然垂到桌面，登桌与投掷时双腿都被袍摆覆盖。为东京男性重复同一流程：Normal 靛蓝短外套和白头巾，Fever 樱纹短外套与织纹腰带，Inferno 深蓝浴衣、花火羽织、金带。每次只交一人一态。独立原画透明底，合成校样再放入同一张桌子。
```

**交件与验收。** 六张单人造型、六张同机位实景小样、男女头像各一件。Normal 与 Fever 的人物站桌后；Inferno 把重量落到原桌面，投掷手高于桌后姿态。脸和手在三态中都能认出。长袍遮腿时靠桌面接触阴影、袍缘承重褶和身体重心交代重量。用正式游戏机位截取抬手与出手两帧，在小屏上复查宽袖是否吞掉瓶颈。


### 07｜画动作关键帧，逐帧验证手、脚和实物

**输入与需求。** 使用同一人物的已选母稿，先在桌子和护栏的线稿上排动作，再拆成单人帧。所有动作沿用同一局部画布、鞋底基线和镜头。表中时间用来剪评审样片，正式投掷、接收、结算以游戏事件为准。

| 动作族 | 必画的关键姿势 | 评审用节奏 |
| --- | --- | --- |
| 跑步、选中、接收及反应 | 左落地、经过、右落地、经过；选中局部描边；伸手接住、收手回跑。另画感谢、欢呼、疼痛、惊讶、失望的面部变化 | 跑步试 6–10 姿势循环；接收或命中反应试 200–500 ms |
| 桌后待机、换物 | 持物待机、伸向备用槽、抓取、举手亮物、回弹待机；备用槽位置稳定 | 待机 2–4 s 一轮；换物 250–450 ms，可连续触发 |
| 桌后／桌上投掷 | 准备握紧、引臂、最后接触帧、手指张开、空手随挥、回收；桌上版维持重心 | 以释放与命中事件标记对位，拖尾只在飞行期间出现 |
| 登桌、稳定、下桌 | 起势、踩桌、重心上移、双脚承重、桌上投掷、逐步返回桌后 | 登桌试 500–800 ms；下桌试 350–650 ms |
| 成功庆祝与错误恢复 | 成功短抬手／跑者小跳；错误则收手或短促失望，随后回到原动作 | 让反应随反馈结束，下一次操作仍可表达 |

**出图指令**


### 09｜制作换物、命中、连击与城市特效

**输入与需求。** 使用已经排好数字的东京实景小样。每个效果交独立透明素材、正常动态与减少动态两版。效果分别挂在手、物体、接收点、得分框和天空；相邻事件连续触发时仍要分得清发生地点。

| 事件 | Normal | Fever | Inferno |
| --- | --- | --- | --- |
| 换补给／手位 | 大颗金星从掌旁弹出，数字轻放大再收回 | 橙红短焰、星星、金色光环 | 紫粉短爆、扩张冲击环、放射火花；手中实物重新显露 |
| 投掷／接收 | 轻弧线和局部小亮圈 | 较长暖色拖尾，接收时短促亮环 | 短而强的出手爆点和局部重命中，主物轮廓贯穿飞行 |
| 得分／连击 | 分数框单次弹动 | 框边火苗随连续成功逐级加高 | 入场一次亮起，高分时只在分数或 Combo 框外沿爆燃；数字位于火焰前层 |

| 减少动态／较低画质 | 静态星与明确选中态 | 暖边色、模式牌、短淡入 | 金紫边色、静态庆典剪影、清晰模式与数值；省去震屏、扫屏与强闪 |


- **尺寸。** 全景、灰模和审片横屏基准 1280×720。需要绘画细节时可用同构图 2560×1440 原稿。透明单件按校样里的最大投放尺寸决定画布，建议先画约 2 倍再缩；独立瓶子或人物允许高于宽。宽高、裁边与像素密度写进导出记录。
- **真分层。** 人物至少有发／饰、脸、躯干／衣服、前后手臂、手指覆盖层、鞋或袍摆、独立补给。场景保留远景、城市物件、观众、护栏、路面、桌体前后、光效。气泡底、胸牌底、动态数值、短句与 HUD 分层。保存 PSD、Krita 或实际采用的分层格式；已有矢量底板也可保存原生 SVG／AI。
- **图像与图集。** 透明无损 PNG 作基准。WebP 与 PNG 以胸牌边缘、手指、发丝、烟花半透明边比较后选用。动作帧采用统一画布或保存原始尺寸、裁切偏移；图集预留外扩边防止邻帧采样。关掉一层再开一次，检查真实 alpha 和独立可替换性。
- **记录。** 每项写资产 ID、素材类别、城市、人物／模式／动作、版次、参考图及原作者／生成来源、使用条件、母稿与导出路径、评审图、审核意见和日期。沿用 `planned → sketch → review → approved → produced → tested`。附有样图的条目起初可记 `review`，实际审核结果填入后再推进。

**帧元数据示例。** 下例演示字段和坐标口径，所有数值仅为示例，实际导出时由美术工具读取。原点在左上，单位为像素，X 向右、Y 向下。`rect` 是图集上的 x、y、宽、高；`trimOffset` 是裁后左上在原帧中的位置；`pivot` 与人物锚点均在原始局部画布中。桌锚由场景母版记录，备用槽由屏幕布局记录。
