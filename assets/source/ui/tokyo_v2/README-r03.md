# Tokyo V2 blank UI skins — Step 10

30 standalone, transparent SVG components: seven top-HUD shells per mode (race, progress, time, score, two-line festival banner, pause, fullscreen) and nine common blank/selection/press states. The common set lives under `normal/` solely as a directory convention; `layout_r03.json` resolves it from all three modes. No runtime variable numerals, native athlete reactions or event titles are baked into these masters. Mode-name badges appear only in composed review text. [UI index](ui_components_index_r03.json), [layout anchor JSON](layout_r03.json), [sample review](../../../previews/steps09-10/tokyo_female_three_modes_approved_camera_contact_r03.svg).

Player-visible original Japanese festival titles and English descriptive samples are preview-only until cultural verification. Any runtime integration requires a separately approved code-change scope.
