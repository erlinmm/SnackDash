# Tokyo Demo V2 illustrated review assets — r02

Status: review, NOT final approved production artwork. This directory supplements the original Step 05–08 source tree; none of the existing original assets or source sequences are deleted.

Renderer baseline: 8ea936a258c4df0b31cc5d306f600213634d41c1. Source asset baseline: 5cd2840daaef280f239fd3b404cc146572c030ed. The supplied three Tokyo references (Normal, Fever, Inferno) and the existing approved Tokyo street plates govern visual direction.

The original street raster resources are retained without changing their bytes. Original sound cues and event FX sequences remain in their existing source directories. This supplement provides independent WebP atlas pages and per-frame metadata for a nine-appearance illustrated runner pilot cast, male and female staff, independently clipped spectators and their frame sequences, station body, tabletop and three scroll skins, decorative bottles, UI skins/logo/titles, petals and isolated firework animation. The original 22-runner editable source cast remains available; the illustrated pilot does not claim to replace all 22 identities yet.

Source construction: illustrated runner/staff frames combine previously prepared raster character art, isolated artwork from the supplied reference sheets, the generated transparent female staff action sheet and adaptations of the earlier run/action timing and anchor definitions. Some intermediate poses use offline raster deformation/pose reuse rather than independently redrawn cels. Crowd groups derive from individually isolated spectators and offline multi-frame movement, not from a flattened gameplay screenshot. Fireworks derive from isolated reference artwork. This is an integration-quality candidate, with detailed hand/foot and animation continuity still subject to visual review. The gameplay screen is not stored as a background.

Each atlas is only source pixel storage. resources.json maps each logical frame to a crop and untrimmed sourceSize/trimOffset. clips.json records explicit frame durations, pivots, hand/head/bib/prop anchors, and transition markers. actors.json maps actions and mode variants. transitions.json preserves costume -> table contact -> kick -> stand and descent -> ground contact -> costume -> three independent pickups/placements. World/HUD/effect/audio configuration is separate. The data is consumed by the existing Landscape Engine V2 compiler and player, with no renderer code changes. New art is explicitly reviewFallback and cannot be formally released until approved.

Build integration: demov2 uses a separate assets/cities/tokyo-demo/pack.json, sharing the original Tokyo source assets and the parts in this directory. The existing technical Tokyo pack and qa-london contract fixture remain intact.
