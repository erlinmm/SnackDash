# Step 06 / 07 — Tokyo station staff SVG model sheets

This folder holds six layered, editable SVG costumes (male/female × Normal/Fever/Inferno) and 8–9 visual action key poses per costume, retaining same head/skin/hair within each gender. Costume and body are explicitly separated into editable SVG groups. A water-bottle prop is a named removable group; it disappears from the hand after the release frame.

Inferno long garments hang to the hem line and conceal legs. The same table position is used in review scenes. **These are draft stylized vector key poses rather than production-approved animations;** motion interpolation, device legibility and event sync remain to be checked. Runtime uses existing throw and target events. No code changes.
