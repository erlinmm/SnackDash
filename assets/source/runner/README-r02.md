# Step 05 — Runner cast and Step 07 gait / reaction sketches

22 independent, original editable SVG runner masters: 11 language/nationality profiles × 2 requested visual examples. The country metadata **does not** determine appearance in the running game. These are intentional visual casting samples with modern unbranded clothing.

Every runner has a frontal 8-pose run loop (100 ms / keyframe **review timing only**), catch pose, thanks, pain, surprise, disappointment, a blank bib, group-labelled vector layers, and JSON review anchors. Handed bottle and bib digits must be separate at runtime. Status **review**, not approved/tested. Coordinates in JSON are draft anchors, not measured export positions.
