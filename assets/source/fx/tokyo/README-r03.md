# Tokyo visual FX — Step 09

The 7 event families are `swap`, `throw`, `receive`, `score`, `mode_enter`, `mode_exit`, `miss`. Each has `normal`, `fever` and `inferno`, then separate `normal` and `reduced` motion variants. Under each event variant: `master.svg` (transparent peak), numbered `frame_*.svg` and `timeline.json` (illustrative timing, semantic event anchors and masks). City atmosphere has 3 × 2 source SVGs. The score/combo frame has an **empty center** for independent runtime digits. All FX are user-event-driven drawing layers, not new scoring code.
